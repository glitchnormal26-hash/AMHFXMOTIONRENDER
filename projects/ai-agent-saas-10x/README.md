# AI Agent SaaS — 10x Motion Batch

One-off production branch for ten individual, brand-neutral AI Agent SaaS product-promo motion explainers.

## Direction
- iOS-inspired UX/UI: rounded translucent surfaces, system typography, compact controls, calm hierarchy.
- No visible product/company branding or logos.
- Internal micro-motion on every concept.
- One continuous product world per concept; no presentation-style screen swapping.
- Authored camera changes and readable settle states.
- No audio.

## Delivery target
- 3840×2160 MP4
- 24 fps
- H.264
- target video bitrate ~18 Mbps, max ~24 Mbps
- 8 seconds each
- 16:9

## Concepts
1. Agent Inbox — route every request
2. Research Map — from question to evidence
3. Meeting Copilot — turn talk into action
4. Revenue Agent — qualify, personalize, book
5. Support Agent — resolve with context
6. Finance Ops — close the loop faster
7. Incident Agent — detect, explain, repair
8. Daily Agent — one plan from every signal
9. Agent Team — specialists that hand off
10. Knowledge Agent — ask once, trace every answer

This branch intentionally keeps the production isolated from main, following the repository's one-off project guidance.

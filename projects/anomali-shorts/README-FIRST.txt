PAKET YOUTUBE SHORTS — ANOMALI FILES (10 VIDEO)
=================================================

FORMAT
- Rasio: 9:16 vertikal
- Resolusi: 1080 × 1920
- Frame rate: 24 fps
- Durasi: 39–49 detik per video
- Audio: voice-over Bahasa Indonesia
- Gaya: fiksi analog horror, procedural motion graphics, overlay teks ala TikTok

PENTING
Semua cerita adalah FIKSI orisinal. Label “FIKSI • ANALOG HORROR” sudah tampil di setiap video agar tidak menyesatkan penonton.

CARA UPLOAD
1. Gunakan judul, deskripsi, hashtag, dan jadwal di UPLOAD-GUIDE.csv.
2. Upload dalam urutan 01 sampai 10 agar format “FILE” terasa seperti satu serial.
3. Jangan tambahkan musik berhak cipta. Voice-over sudah tertanam.
4. Pilih frame hook awal sebagai cover bila YouTube meminta frame sampul.
5. Balas komentar dengan pertanyaan terbuka untuk mendorong percakapan, misalnya: “Kalau kamu lihat tombol 0, kamu tekan atau kabur?”

CATATAN MONETISASI
Paket ini dirancang untuk retensi dan konsistensi serial, tetapi tidak ada konten yang dapat menjamin viral atau monetisasi. Hindari membeli view/subscriber dan patuhi kebijakan YouTube Partner Program.

SUGGESTED CHANNEL IDENTITY
- Nama seri: ANOMALI FILES
- Handle visual di video: @ANOMALI.FILES
- Palet: hitam arang + warna per file
- Format lanjutan: FILE 011, 012, dan seterusnya

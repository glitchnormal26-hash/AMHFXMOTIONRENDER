# Autumn Landscape / Outdoor — 10 Seamless Motion Loops

- 10 variants (`?v=1` … `?v=10`)
- no text, copyspace-led framing
- 16:9
- deterministic 10-second loop
- Three.js HTML
- supports 4K render size with `?w=3840&h=2160`

Examples:

```text
autumn_variations.html?v=1&w=3840&h=2160
autumn_variations.html?v=10&w=3840&h=2160
```

The page exposes `window.renderAt(seconds)` for frame-accurate render pipelines. Time is modulo 10 seconds, and all animation functions are periodic at exactly 10 seconds.

Variants:
1. Misty Forest Corridor — edge trees, open upper-right copyspace
2. Golden Lakeside — low mountains/lake, open sky copyspace
3. Rolling Hills — layered warm hills, tree cluster left
4. Leaf Tunnel — branch frame and denser edge leaves
5. Riverside Path — diagonal water, forest edge
6. Birch Grove — pale trunks framing central copyspace
7. Pumpkin Meadow — low foreground pumpkins, open upper-right
8. Mountain Overlook — low mountain silhouette, broad sky
9. Golden Field — waving grass and lone tree left
10. Leaf Vortex — abstract spatial leaf orbit, right-side copyspace

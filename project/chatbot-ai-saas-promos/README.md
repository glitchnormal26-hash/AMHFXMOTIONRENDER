# AI Chatbot SaaS Promo — 10 concepts

One-off production branch for ten distinct AI-chatbot SaaS motion promos, created using the AMHFX Motion Designer v3.9.4 direction, camera, anti-PPT, visual-quality, explainer, and SaaS-profile rules.

## Delivery

- 10 individual MP4 clips
- 16:9, final stream 3840x2160
- H.264 / yuv420p
- 24 fps
- medium target bitrate (20 Mbps target; VBR varies by scene complexity)
- no audio
- no visible logo or third-party branding
- minimal product UI copy only
- durations roughly 6.4–6.8 seconds each

Generated media is intentionally not committed to the repository, following MANAGE.md. Delivery media and encoded-frame QA are attached in the ChatGPT task output.

## Concepts

1. Customer support smart reply / live inbox
2. Sales lead qualification / fit score
3. Internal knowledge assistant / cited answer
4. Chatbot analytics / resolution & response metrics
5. User management / team access
6. Multi-channel support / unified inbox
7. AI-to-human escalation / handoff
8. Automation routing / classify-route-update-resolve
9. Conversation QA / sentiment analysis
10. Conversation search / matched thread

Each concept uses a different composition, hero interaction, palette, camera path, and internal micro-motion language.
